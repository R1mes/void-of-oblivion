# Правила Antigravity для проекта Void of Oblivion

## Экономия токенов
1. **Точечное чтение**: Никогда не читать весь файл целиком, если он больше 150 строк. Использовать `grep_search` и `view_file` с `StartLine/EndLine`.
2. **Сначала план — потом код**: Сначала чёткий короткий план действий, затем реализация.
3. **Краткость ответов**: Отвечать ёмко, без разжёвывания очевидного и без пересказа документации.
4. **Инструменты**: Не использовать скриншоты и веб-браузер для задач по логике и формулам.

## Архитектура и ограничения
* Движок: Godot Engine 4.6 (GDScript со статической типизацией).
* Все расчёты урона и пробития — строго через `DamageCalculator` и `BattleManager`.
* Никаких прямых хардкодов формул в классах способностей персонажей.
* Не трогать `security/`, `*.key`, `firebase.json`, `firestore.rules`, `export_presets.cfg`, `user/`, `user_data/`.

## Проверка правок
* Тесты запускать через `/Applications/Godot.app/Contents/MacOS/Godot --headless --path . tests/<suite>.tscn`
* Проверять код возврата (0) и отсутствие `SCRIPT ERROR`.

# Документация проекта Void of Oblivion

## Архитектура
Проект построен по модульному принципу на Godot Engine 4.6 (GDScript):

* **Боевое ядро (`scripts/combat/`)**:
  * `battle_manager.gd` — центральный менеджер боя (очередь ходов, цикл действий, обработка эффектов начала/конца хода, начисление очков действий и энергии).
  * `damage_calculator.gd` — единый калькулятор прямого урона, урона пробития (Break DMG), суперпробития (Super Break DMG), критических ударов, сопротивлений и срезов защиты.
  * `toughness_system.gd` — система истощения стойкости, пробития уязвимостей и наложения статусов пробития.
  * `combat_unit.gd` / `combat_stats.gd` — базовые сущности участников боя и их эффективных характеристик.
  * `memosprite/` — подсистема Духов Памяти (призыв, привязка к наставнику, независимая шкала действий, передача урона, автобой/ручное управление).
  * `faction_system.gd` — синергии фракций («Хранители небес», «Свечение» и др.) и механика Звёздных проводников.
* **Персонажи и Способности (`scripts/characters/`)**:
  * Каждый персонаж имеет модуль способностей с фабрикой юнита (`create_unit`), описанием базовой атаки, навыков (Q/E), ультимейта, таланта и эйдолонов.
* **Враги и Боссы (`scripts/enemies/`)**:
  * Фабрики и скрипты ИИ для обычных противников, элитных монстров и боссов фаз.
* **Реестры и Данные (`scripts/data/`)**:
  * `character_registry.gd`, `light_cone_registry.gd`, `relic_system.gd` — реестры персонажей, световых конусов и сетов реликвий.
* **Сетевой слой и Облако (`scripts/network/`)**:
  * Интеграция с Firebase Auth и Cloud Firestore (аутентификация, сохранение профиля, крутки баннеров).
* **Пользовательский интерфейс (`scenes/`, `scripts/ui/`)**:
  * Сцены меню, выбора отряда и боевого интерфейса, `battle_info_provider.gd` для генерации описаний способностей, статусов и баффов.

## Как запускать локально
1. **Через Godot Editor**:
   * Открыть проект в Godot Engine 4.6 (`project.godot`).
   * Нажать `F5` (запуск проекта) или `F6` (запуск текущей сцены).
2. **Через терминал (CLI)**:
   ```bash
   /Applications/Godot.app/Contents/MacOS/Godot --path .
   ```

## Как проверять изменения
Для проверки логики без запуска графического окна используются headless-автотесты:

* **Все тесты Духов Памяти (Memosprites)**:
  ```bash
  /Applications/Godot.app/Contents/MacOS/Godot --headless --path . tests/test_runner.tscn
  ```
* **Тесты Марины • Хранитель небес**:
  ```bash
  /Applications/Godot.app/Contents/MacOS/Godot --headless --path . tests/test_marina_runner.tscn
  ```
* **Тесты Ленской • Хранитель небес**:
  ```bash
  /Applications/Godot.app/Contents/MacOS/Godot --headless --path . tests/test_lenskaya_runner.tscn
  ```

**Критерии успешности**:
* Код завершения процесса `0`.
* Отсутствие `SCRIPT ERROR` в консоли.
* Все тесты в сьюте отмечены как `[PASS]`.
